# College Management System

A full-stack College Management System developed to simplify and manage college-related activities through a web application.

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3
- React Router DOM
- Vite

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- Maven

### Database
- PostgreSQL

## Features

- User Authentication
- Role-Based Access Control
- Student Management
- Faculty Management
- Course Management

## Installation and Setup

### Prerequisites
- Java JDK
- Node.js and npm
- PostgreSQL
- Maven

### Backend Setup

1. Open the backend folder in your IDE.
2. Configure your PostgreSQL database connection.
3. Run the Spring Boot application.

### Frontend Setup

1. Open the frontend folder in the terminal.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL displayed in the terminal.

## Database Configuration

- Database: PostgreSQL
- Database Name: college

Configure the database username and password in the backend application settings.
